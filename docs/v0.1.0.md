# Sentinel EU Demo App — Version `v0.1.0`

## Release Summary

`v0.1.0` is the first publishable release of the Sentinel EU Demo App.
It provides a Streamlit-based operator experience for monitoring simulated or uploaded location telemetry, reviewing incidents, investigating subjects, and demonstrating hybrid Python + Oracle workflows for spatial and vector-assisted anomaly handling.

## What Is Included

### Core application
- Streamlit user interface with workspace-driven navigation
- EU synthetic telemetry generation
- GPX upload support
- Template-based synthetic route generation from GPX
- Rule-based alerts and co-location detection
- Risk scoring and hybrid decision support
- Oracle integration for baseline and converged schema demos
- LLM-assisted operator triage through Ollama or OCI GenAI

### Main workspaces
- **Operations Center**
  - incident overview
  - prioritized incident queue
  - escalation banners
  - operator attention feed
  - live map with selectable subjects
- **Subject Investigation**
  - subject selector
  - subject-specific map focus
  - alerts, device, track, risk, and behavior views
- **Hybrid Intelligence**
  - behavior vectors
  - matched patterns
  - decision outcomes
  - Oracle hybrid query results
- **Data & Scenarios**
  - dataset generation and source switching
  - presentation scenarios
  - synthetic population controls
- **Oracle Lab**
  - schema setup
  - data push to Oracle
  - converged demo loading and execution

## Supported Data Modes

- **Presentation scenarios**
  - curated demo subjects for routine, elevated-risk, and outside-zone scenarios
  - optional additional synthetic background subjects
- **EU synthetic**
  - generated movement data across seeded European cities
- **Template-based synthetic**
  - clones a GPX movement pattern across multiple generated subjects
- **GPX upload**
  - loads one or more uploaded GPX tracks directly into the monitoring pipeline

## Key Features in `v0.1.0`

### Monitoring and triage
- clickable incidents and map objects
- subject drill-down from the UI
- anomaly focus with map zoom-to-subject behavior
- operator-facing escalation banners
- manual incident trigger panel for demos and testing

### Detection and scoring
- exclusion-zone alerting
- device-related flags
- simultaneous co-location detection
- risk scoring pipeline
- behavior vector generation and pattern matching
- hybrid decisioning with outcomes such as `ELEVATE`, `REVIEW`, `DEPRIORITIZE`, and `NO_ACTION`

### Oracle capabilities
- baseline relational persistence
- dedicated Oracle schema bootstrap for the `sentinel` user
- Oracle 26ai converged schema with spatial/vector demo tables
- Oracle-side hybrid query workflow for presentation scenarios

## Repository Layout

- `app/main.py` — Streamlit app and UI workflows
- `app/simulator.py` — synthetic EU telemetry generation
- `app/kaggle_loader.py` — GPX parsing helpers
- `app/detection.py` — alerts, co-location, and risk logic
- `app/behavior.py` — presentation scenarios and hybrid decision support
- `app/llm_client.py` — Ollama and OCI LLM abstraction

- `sql/schema_oracle_26ai.sql` — baseline relational schema
- `sql/schema_oracle_26ai_converged.sql` — Oracle 26ai converged schema

## Runtime Defaults

- Streamlit default port: `8502`
- Default Oracle user: `sentinel`
- Default Oracle DSN: `localhost:1521/FREEPDB1`
- Default local LLM mode: Ollama

## Installation

### Local
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app/main.py
```

Open `http://localhost:8502`.

### Docker Compose
```bash
docker compose up -d --build
```

If using Ollama from the host machine, point the app to `http://host.docker.internal:11434`.

## Oracle Setup

Create the dedicated schema user:

```bash
docker exec -i oracle26ai sqlplus system/OraclePwd123@localhost:1521/FREEPDB1 < sql/create_sentinel_user.sql
```

Create the baseline schema:

```bash
docker exec -i oracle26ai sqlplus sentinel/SentinelPwd123@localhost:1521/FREEPDB1 < sql/schema_oracle_26ai.sql
```

Create the converged demo schema:

```bash
docker exec -i oracle26ai sqlplus sentinel/SentinelPwd123@localhost:1521/FREEPDB1 < sql/schema_oracle_26ai_converged.sql
```

## Known Scope for `v0.1.0`

This release is intended as a demo and presentation build. It focuses on usability and scenario coverage rather than production hardening.

Current scope limits include:
- no formal authentication or multi-user access control
- no persistent incident lifecycle management beyond the current session/demo flow
- no background streaming service; “real-time” behavior is driven by Streamlit reruns and operator actions
- no packaged API layer for external integrations yet
- no audio or transcript tooling in this release

## Recommended Demo Flow

1. Start the app on `8502`.
2. Select `Presentation scenarios`.
3. Increase `Participants` if you want richer background activity.
4. Use `Operations Center` to review overview cards, map focus, and the incident queue.
5. Click an incident or subject to open focused investigation.
6. Use `Trigger Test Incident` to validate escalation banners and operator attention handling.
7. Open `Oracle Lab` to load and execute the converged demo path.
